## 🌟 About The Project

**DhanSetu Loan App** is a modern Android application designed to provide users with a simple and convenient digital loan experience.

The application is built using **Kotlin** and is structured as a native Android project.

> 🚀 Built to explore modern fintech and digital lending experiences.

---

## ✨ Features

* 👤 **User Registration & Profile**
* 🔐 **Secure Authentication**
* 💰 **Loan Application**
* 📋 **Loan Details**
* 📊 **Loan Status Tracking**
* 💳 **Repayment Management**
* 📜 **Transaction History**
* 🔔 **Notifications**
* 📱 **Modern Android UI**
* ⚡ **Fast & User-Friendly Experience**

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/luciferofx/DhanSetu-Loan-app.git
```

### 2️⃣ Open Project

Open the project in **Android Studio**.

```text
Android Studio
      ↓
Open Project
      ↓
DhanSetu-Loan-app
      ↓
Gradle Sync
      ↓
Run ▶
```

### 3️⃣ Configure Environment

If required, create your local environment configuration using:

```text
.env.example
```

⚠️ **Never upload API keys, passwords, Firebase credentials, private keys, or other secrets to GitHub.**
